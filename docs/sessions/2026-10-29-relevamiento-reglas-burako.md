# 2026-10-29: Relevamiento y acuerdos de reglas de Burako

## Objetivo

Investigar reglas del Burako argentino con fichas, contrastar reglamentos publicados y preparar una guía para fijar las reglas de esta mesa. El relevamiento inicial quedó registrado en el commit `884109f`.

## Trabajo realizado

- Se compararon fuentes del fabricante, un reglamento institucional, reglas de una aplicación y un reglamento de torneo.
- Se preparó un compilado breve que distinguía reglas de referencia de variantes habituales, para no mezclar sin acuerdo reglas de distintas ediciones.
- En una actualización posterior ese mismo día (`f54e807`) se pasó de una guía general a reglas acordadas para esta mesa y se explicitó cómo resolver los puntos variables.

## Fuentes

El commit inicial `884109f` incluye estas referencias:

- [Ruibal: Reglas de juego Burako (PDF)](https://www.ruibalgames.com/wp-content/uploads/2015/10/Reglas-de-juego-Burako.pdf), reglamento del fabricante para el juego con fichas.
- [Juegos Bonaerenses: reglamento de Burako (PDF)](https://juegos.gba.gob.ar/wp-content/uploads/2026/reglamentos/especificos/deportes_adultos_mayores/burako.pdf), ejemplo de reglamento institucional.
- [ConectaGames: reglas de Burako](https://www.conectagames.com/rules/burako?lang=ES), reglas de una aplicación y variantes relacionadas.
- [Liga Country Sur: Reglamento de Burako (PDF)](https://ligacountrysur.com.ar/media/REGLAMENTO%20DE%20BURAKO.pdf), ejemplo de reglamento de torneo.
